# Printing Parts 3D

Website for Printing Parts 3D.

## Pages

- `index.html` - homepage
- `about.html` - company and engineering approach
- `technologies.html` - FDM, MSLA, and laser services
- `process.html` - project workflow
- `materials.html` - printing material families
- `contact.html` - project intake and contact form

## Local preview

```sh
npm run dev
```

Then open `http://localhost:3000`.

## Wix Headless

The project enquiry form is submitted through a Netlify Function and stored in Wix Forms. See [WIX_HEADLESS_SETUP.md](WIX_HEADLESS_SETUP.md) for the required Wix form, credentials, and Netlify environment variables.
