# Prompt: Technology Gallery

Create a full-width RTL Hebrew technology section for an industrial 3D-printing website.

- Use the brand navy background (`#252833`) with a subtle 56px engineering grid.
- Place a small section index at the top-right: orange number, thin white rule, Hebrew label.
- Use a two-column heading row: a large thin modern Hebrew headline on the right and a short muted explanation on the left.
- Below it, create three equal image cards for FDM, MSLA and laser cutting.
- Cards must be tall and immersive, with edge-to-edge industrial photography and a dark lower overlay for readable copy.
- Put the orange index, title, description and left arrow at the bottom-right of each card.
- On hover, lift the card by 8px, brighten and slightly zoom the image, emphasize the orange border and move the arrow left.
- Reveal every image once from right to left when it first enters the viewport.
- Use square or slightly rounded corners only, high text contrast and a responsive single-column mobile layout.
- Keep all selectors scoped under `.pp3d-tech` so the component can be embedded without changing the host website.
