# Technology Gallery

Portable version of the “הטכנולוגיה הנכונה לכל יישום” homepage section.

## Files

- `section.html` — component markup
- `section.css` — fully scoped visual system and responsive rules
- `section.js` — one-time right-to-left image reveal
- `assets/` — local component images
- `PROMPT.md` — reusable generation prompt
- `demo.html` — isolated live preview

## Embed

Copy the component folder into the target project, include `section.css`, paste the markup from `section.html`, and load `section.js` after the markup. Keep the relative `assets/` paths together with the component.
